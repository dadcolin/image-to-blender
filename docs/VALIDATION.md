# Validation of the first portable release

Checked on **2026-11-05**. This separates real model history, actual portable CPU/Blender checks, and simulated adapter tests.

- **Real model history:** the lamp native PLY came from the completed IDOL run on DGX Spark. Its SHA256 is `adc898bbcfbd8abe31114b2fec07e5f997b92ac4cb714352ee3d3a1693b9314b`. See [example provenance](../examples/lamp/provenance.json). We did not rerun GPU inference during packaging or interrupt any serving process.
- **Portable CPU conversion:** the new package processed that exact PLY into 179,005 vertices / 354,288 triangles, wrote NPZ, triangle PLY and the JSON import bundle, with relative-path SHA binding. The guarded stage took 31.346 seconds and sampled about 294 MiB peak RSS on this execution. This is a single additional validation observation, not a replacement throughput benchmark.
- **Actual `.blend` export:** Windows Blender 5.2.3 LTS saved and freshly reopened the portable output. Vertex positions, triangle indices, vertex colors and Edit Mode were checked. Uniform height 500 mm and independent XYZ 300/250/500 mm both passed; the latter persisted approximately 299.999997 / 250 / 499.999985 mm. These are **demo targets**, not measurements of the physical lamp.
- **Independent add-on ZIP:** Blender's own extension manifest validation/build succeeded. The ZIP was installed and enabled in an isolated user profile, then tested in a separate Blender process. It imported the actual lamp bundle, preserved pre-existing scene objects, set whole height to 500 mm, and sized selected part vertices with a rotated/scaled object in a centimeter scene. Unselected vertices and the object matrix were unchanged. Overflow targets were rejected without changing geometry. The extension disabled and Blender exited cleanly. No existing personal Blender preferences were changed.
- **Python suite:** 55 tests and 42 unittest subtests passed locally on Python 3.13.14. These cover actual small density reconstruction, covariance/color/axis handling, image/source hash binding, metadata stripping, dimensions, path escape/tamper rejection and child-process cleanup. Upstream scikit-image/NumPy deprecation warnings remain, without test failures.
- **Inference adapter tests:** 25 of the tests use explicitly simulated Torch/IDOL/Hugging Face objects to check argument forwarding, files, hashes, failure propagation and no retry. They do **not** demonstrate a fresh GPU run of the repackaged adapter. The independent adapter still needs testing on additional GPU platforms; the reference model execution is documented separately.

The add-on declares Blender 4.2 as its API minimum; **only 5.2.3 LTS was actually exercised here**. No claim is made that every older version, driver, architecture, object class or dependency combination was tested. A Linux Python 3.11/3.12 Actions template is provided under `docs/ci/`. Automatic CI is not enabled in this initial release: the publishing OAuth credential lacks GitHub workflow scope. No Linux CI pass is claimed.

The public lamp `.blend` and PNGs are separately sanitized copies of the original reviewed example. Their geometry/colors and decoded image pixels were compared to the originals, and the fresh scene was reopened. This file describes technical checks, not a blanket visual, dimensional, CAD, fabrication or commercial-rights approval.
